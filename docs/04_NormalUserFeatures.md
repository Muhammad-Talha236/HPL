# Normal User Features

## 1. Overview

A **Normal User** is a general registered user of the football league platform.

Normal users can view football information, follow teams, check matches, and stay updated with league activities.

They cannot manage official league data.

---

## 2. Home Page

Normal users can access the public home page.

### Features

* Latest football news
* Upcoming matches
* Recent results
* Featured teams
* Featured players
* Current competitions
* Important announcements

---

## 3. Men's & Women's Football

Normal users can access both men's and women's football sections.

### Men's Football

* View men's statistics

### Women's Football

* View women's teams

---

## 15. Team Registration

A normal user can also become a **Team Owner/Manager** by registering an independent team.

The process is:

```text id="0m29j5"
Normal User
     ↓
Register Team
     ↓
Submit Team Information
     ↓
Select Competition
     ↓
Super Admin Review
     ↓
Approved
     ↓
Team Owner/Manager
     ↓
Team Portal
```

After approval, the user receives management access to that specific team.

The user's normal account remains a **Normal User** globally.

---

## 16. Access Restrictions

A Normal User cannot:

* Manage clubs
* Manage other teams
* Manage players
* Create official matches
* Modify match results
* Modify standings
* Create competitions
* Approve registrations
* Manage league settings
* Access Super Admin features

A Normal User can manage an independent team **only after becoming its approved Team Owner/Manager**.
